# Advent of Code

My solutions to [Advent of Code](https://adventofcode.com), the yearly advent calendar of programming puzzles, written in [Julia](https://julialang.org).

| Year | Days | Folder |
|------|------|--------|
| 2025 | 1–12 | [`2025/`](2025) |
| 2024 | 1–25 | [`2024/`](2024) |

Each day is a single script (`DayXX.jl`) that solves both parts of the puzzle and prints the answers.
